Smiley Icon Test

This page does nothing. It exists to check which icon iOS picks when you save it to the Home Screen.

Try it

  1. Open this link in Safari on your iPhone (not the Claude app's in-app browser).
  2. Tap the Share button, then Add to Home Screen.
  3. The preview in that sheet should already show the smiley. If it shows a screenshot of the page instead, Safari didn't find the icon.
